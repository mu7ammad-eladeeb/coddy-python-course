# Python: How It Began

## 1989

### **Learning from ABC**

Python borrowed many ideas from ABC, a language for beginners that Guido had helped build at CWI. He kept what worked, like readable code grouped by indentation, and fixed what held ABC back, such as being hard to extend.

- **ABC:** An early programming language designed to be easy for beginners to learn and use. It influenced Python's design.
- **Guido:** Guido van Rossum, the creator of Python.
- **CWI:** Stands for *Centrum Wiskunde & Informatica*. It is a research institute in the Netherlands focused on mathematics and computer science.
- **Readable code:** Code that is easy for people to understand.
- **Indentation:** The spaces at the beginning of a line of code. Python uses indentation to show which statements belong together in a block.
- **Extend:** To add new features or capabilities to a programming language or software.
- **Hard to extend:** Difficult to modify or build upon by adding new features.
- **Influence:** To have an effect on how something is designed or developed.

**Source:** python.org (Added details by ChatGPT)

## 1989

### **Not named after a snake**

Guido named his language after Monty Python's Flying Circus, the British comedy show. He wanted a name that was short, unique and slightly mysterious.

- **Guido:** Guido van Rossum, the creator of Python.
- **Monty Python's Flying Circus:** A British comedy television show known for its unusual humor and sketches. It inspired the name “Python.”
- **British:** Related to Great Britain, which includes England, Scotland, and Wales.
- **Comedy show:** A television program designed to make people laugh.
- **Unique:** Different from others or not common.
- **Mysterious:** Something that is unusual or not immediately easy to understand.
- **Snake:** A legless reptile. Although Python is also the name of a group of snakes, the programming language was named after the comedy show, not the animal.

**Source:** docs.python.org (Added details by ChatGPT)

## 1991

### **Released to the world**

In February 1991, Guido posted Python 0.9.0 to the alt.sources newsgroup. It already had classes, functions, exception handling and core types like lists and dictionaries.

* **Guido van Rossum:** The Dutch programmer who created the Python programming language, serving as its "Benevolent Dictator For Life" (BDFL) until stepping down in 2018.
* **Python 0.9.0:** The first public release of the Python programming language, published early in 1991 at CWI (Centrum Wiskunde & Informatica) in the Netherlands.
* **alt.sources:** A Usenet newsgroup historically used for sharing and distributing software source code over the early internet before centralized platforms like GitHub existed.
* **Classes & Functions:** Core programming paradigms; classes define blueprints for object-oriented programming (OOP), while functions provide modular, reusable blocks of code.
* **Exception Handling:** A structured mechanism (`try...except`) allowing software to gracefully detect, catch, and respond to runtime errors without crashing.
* **Lists & Dictionaries:** Python's built-in fundamental data structures; lists store ordered, mutable sequences of items, and dictionaries store key-value mapping pairs.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1994

### **Python 1.0**

Python 1.0 came out in January 1994. It added functional programming tools like lambda, map, filter and reduce, contributed by a fan of the language Lisp.

- **Came out:** An informal way of saying that software was officially released and became available to use.
- **Functional programming:** A programming style that emphasizes using functions to transform data and produce results.
- **Lambda:** A Python keyword used to create a small, anonymous function (a function without a declared name). For example, `lambda x: x * 2` returns a function that doubles its input.
- **`map()`:** A function that applies another function to every item in an iterable.
- **`filter()`:** A function that selects items from an iterable when they satisfy a condition.
- **`reduce()`:** A function from Python's `functools` module that combines items in an iterable into a single result by repeatedly applying a function.
- **Iterable:** An object whose items can be processed one at a time, such as a list, tuple, or string.
- **Lisp:** A family of programming languages known for their use of functions and symbolic expressions. It influenced ideas used in many other programming languages.
- **Contributed:** Added or provided something to help develop or improve a project.

**Source:** en.wikipedia.org (Added details by ChatGPT)

## 2000

### **Python 2.0**

Python 2.0, released in October 2000, introduced list comprehensions and a garbage collector that could clean up reference cycles. Its development also became more open to the community.

- **Released:** Officially made available for people to use.
- **List comprehensions:** A concise way to create a new list from an iterable, optionally filtering items or transforming their values. For example, `[x * 2 for x in [1, 2, 3]]` produces `[2, 4, 6]`.
- **Iterable:** An object that can provide its items one at a time, such as a list, tuple, or string.
- **Garbage collector:** A mechanism that automatically identifies and cleans up objects that a program no longer needs, helping free memory.
- **Reference:** A connection from one variable or object to another object in memory.
- **Reference cycle:** A situation where two or more objects refer to one another, directly or indirectly. This can make it difficult to determine whether the objects are still needed.
- **Memory:** The computer space used to store data while a program runs.
- **Community:** The group of people who use, develop, and contribute to Python.
- **Open development:** A way of developing software that makes more of the work, discussions, and decisions visible to the public, allowing community members to participate.

**Source:** docs.python.org (Added details by ChatGPT)

## 2004

### **The Zen of Python**

Tim Peters wrote 19 guiding principles for Python, like "Readability counts". In 2004 they became PEP 20, and you can still read them by typing `import this`.

- **The Zen of Python:** A collection of guiding principles that describe the philosophy behind Python's design and how Python code should be written.
- **Tim Peters:** A Python programmer who wrote these principles.
- **Guiding principles:** Basic ideas or rules that help people make decisions and work consistently.
- **Readability counts:** A principle meaning that code should be easy for people to read and understand, not just make computers perform a task.
- **PEP:** Stands for *Python Enhancement Proposal*. It is a document that describes a proposal, explains a Python feature, or records information and guidelines about Python.
- **PEP 20:** The specific PEP that contains the Zen of Python.
- **`import this`:** A Python command that displays the Zen of Python when entered into a Python interpreter.
- **Python interpreter:** A program that executes Python code.
- **Philosophy:** The set of ideas and beliefs that guide how something is designed or used.

**Source:** peps.python.org (Added details by ChatGPT)

## 2005

### **Reddit switches to Python**

Reddit launched in June 2005 with code written in Common Lisp. Later that year it was rewritten in Python using web.py, a framework by co-founder Aaron Swartz. He said the switch made the code simpler and easier to maintain.

* **Reddit:** A massive social news aggregation, web content rating, and discussion website founded in 2005 by Steve Huffman and Alexis Ohanian, later joined by Aaron Swartz.
* **Common Lisp:** A general-purpose, high-level, object-oriented, dynamic functional programming language in the Lisp family, characterized by a fully parenthesized prefix notation and powerful macro system.
* **Python:** A high-level, interpreted programming language emphasizing code readability, developer productivity, and extensive library support, which enabled Reddit to scale rapidly in its early growth phase.
* **web.py:** A minimalist, lightweight Python web framework designed to be clean, powerful, and easy to understand, created by Aaron Swartz.
* **Aaron Swartz:** An American computer programmer, entrepreneur, writer, political organizer, and internet activist who co-founded Reddit and made foundational contributions to web standards and open access.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 2008

### **Python 3.0: A Major Language Redesign**

Python 3.0 (also known as "Py3K" or "Python 3000") was officially released in December 2008 after years of development led by Guido van Rossum. Designed to clean up the language by rectifying accumulated architectural flaws, it intentionally broke backward compatibility with Python 2.x to avoid legacy constraints. Among many foundational changes, the most instantly recognizable syntax modification was converting the `print` statement into a built-in `print()` function, requiring explicit parentheses.

* **Python 3.0 (Py3K):** A major version release of the Python programming language that prioritized code consistency, cleaner abstractions, and the removal of duplicate features over backward compatibility.
* **Backward Compatibility:** A design property allowing older code or software versions to run unmodified on newer iterations of a platform or language runtime.
* **Print Function:** A fundamental built-in function introduced in Python 3 to handle standard output, replacing the flexible but syntactically inconsistent `print` statement of Python 2.
* **Unicode Defaults:** A core architectural shift in Python 3 that made all standard string types (`str`) default to UTF-8 encoded Unicode, separating textual data cleanly from raw binary bytes (`bytes`).

**Source:** docs.python.org (Added details by Gemini AI)

## 2019

### **The Steering Council**

After Guido stepped down, Python's core developers voted for a new model: a five-person Steering Council, elected regularly. The first council, which included Guido, started in 2019.

- **Steering Council:** A group of people responsible for guiding Python's development and making important project decisions.
- **Stepped down:** Voluntarily left a leadership position or role.
- **Core developers:** Experienced contributors who help maintain and develop Python itself.
- **Contributors:** People who help improve a project by writing code, fixing bugs, reviewing changes, or improving documentation.
- **Model:** A system or structure used to organize how something works.
- **Elected:** Chosen through a voting process.
- **Regularly:** At repeated intervals, according to a schedule.
- **Guido van Rossum:** The creator of Python, who stepped down as its BDFL in 2018 but joined the first Steering Council in 2019.

**Source:** peps.python.org (Added details by ChatGPT)

## 2020

### **Goodbye, Python 2: The End of an Era**

On January 1, 2020, Python 2 officially reached its End of Life (EOL) after running concurrently with Python 3 for over 11 years. Originally scheduled for retirement in 2015, the legacy platform's sunset was extended by half a decade to grant organizations sufficient time to migrate their codebases. The final bug-fix and maintenance release, Python 2.7.18, was officially published in April 2020, marking the permanent conclusion of core security updates and active maintenance from the Python Software Foundation.

* **End of Life (EOL):** The date after which a software platform or operating system no longer receives official security updates, feature enhancements, or maintenance support from its developers.
* **Python 2.7.18:** The final bug-fix and maintenance release of the Python 2 branch, published in April 2020 as a symbolic closure to Python 2's 20-year history.
* **Migration Tools (e.g., `2to3`):** Automated refactoring utilities designed to parse Python 2.x source code and transform it into valid Python 3.x syntax to assist developers during phase-out transitions.
* **Python Software Foundation (PSF):** The non-profit organization that manages Python's intellectual property rights and coordinated the community-wide transition strategy to retire Python 2.

**Source:** python.org (Added details by Gemini AI)

## 2022

### **Faster Python**

Python 3.11, released in October 2022, runs typical programs between 10% and 60% faster than Python 3.10. The speedup came from the Faster CPython project.

- **Speedup:** An improvement that makes a program run faster or complete a task in less time.
- **CPython:** The most widely used implementation of Python. It is written mainly in C and executes Python code.
- **Faster CPython project:** An effort by Python developers to improve CPython's performance so that Python programs run faster.
- **Implementation:** A version of a programming language that makes its rules work in practice. For example, CPython is an implementation of Python.
- **Released:** Officially made available for people to use.
- **10% to 60% faster:** Depending on the program, Python 3.11 could complete certain tasks in less time than Python 3.10. The improvement varies by workload.

**Source:** docs.python.org (Added details by ChatGPT)

## 2024

### **Life without the GIL**

Python 3.13, released in October 2024, added an experimental build without the Global Interpreter Lock. It lets threads run Python code truly in parallel on several CPU cores.

- **GIL:** Stands for *Global Interpreter Lock*. It is a mechanism in Python's standard implementation (CPython) that traditionally allows only one thread at a time to execute Python bytecode within a process.
- **Global:** Applies to the whole Python process rather than just one thread.
- **Interpreter:** A program that executes code written in a programming language, such as Python.
- **Lock:** A mechanism that controls access to a shared resource to prevent conflicting operations.
- **Experimental build:** A version of Python that includes a feature still being tested and developed, so it may not be as mature or widely supported as the standard version.
- **Thread:** A separate path of execution within a program. Multiple threads can help a program handle several tasks.
- **Parallel:** Running multiple tasks at the same time, rather than taking turns.
- **CPU cores:** Processing units inside a computer's processor that can execute instructions. Multiple cores can work on different tasks simultaneously.
- **CPython:** The most widely used implementation of Python, written mainly in C.
- **Bytecode:** A lower-level set of instructions produced from Python code for the interpreter to execute.

**Source:** docs.python.org (Added details by ChatGPT)

## 2000

### **BeOpen PythonLabs: A Pivotal Transition for Python's Core Team**

In May 2000, Guido van Rossum and several core Python developers departed CNRI (Corporation for National Research Initiatives) to join BeOpen.com, forming the BeOpen PythonLabs team. The transition aimed to create an open-source business model around Python, leading to the release of Python 2.0 under BeOpen. However, the dot-com bubble burst led to the startup's rapid collapse by October of that same year. Following the shutdown, the core development team moved to Digital Creations, the company that later became Zope Corporation.

* **BeOpen PythonLabs:** An open-source software venture formed by core Python developers in 2000 to commercialize services around Python while keeping the language open-source.
* **Guido van Rossum:** The creator of the Python programming language, who led the core development team through multiple organizational transitions in the early 2000s.
* **Python 2.0:** A major release of Python published in October 2000 that introduced list comprehensions, a cycle-detecting garbage collector, and enhanced Unicode support.
* **Zope Corporation (formerly Digital Creations):** An open-source web application server company that hired the core Python team in late 2000, providing stability for Python's ongoing development.

## 2007

### **import antigravity: The Iconic xkcd Easter Egg**

In December 2007, Randall Munroe published xkcd comic #353 titled "Python," in which a character flies simply by importing a module called `antigravity`, humorously celebrating the language's elegance and ease of use. Python core developers commemorated the viral comic by officially adding a hidden `antigravity` module to the Python standard library starting with Python 3.0. Executing `import antigravity` opens the original comic webpage directly in the user's default web browser via the standard `webbrowser` module.

* **`import antigravity`:** A famous easter egg built into the Python standard library that automatically launches xkcd comic #353 in a web browser when executed.
* **xkcd:** A popular webcomic created by Randall Munroe in 2005 covering topics in computer science, technology, science, and mathematics.
* **Standard Library:** The extensive collection of built-in modules and packages included with Python out of the box, fulfilling its "batteries included" philosophy.
* **`webbrowser` Module:** A built-in Python module that provides a high-level interface to allow applications to display Web-based documents to users.

## 2005

### **Django Goes Public: The Birth of a Modern Web Framework**

Django was released as open-source software in July 2005 under a three-clause BSD license after initially being developed in 2003 by Adrian Holovaty and Simon Willison at the *Lawrence Journal-World* newspaper. Created to meet fast-paced newsroom deadlines and complex data requirements, the high-level Python framework was named in honor of the influential Romani-French jazz guitarist Django Reinhardt—a personal inspiration to Holovaty, who is also an accomplished jazz guitarist.

* **Django:** A high-level, open-source Python web framework that encourages rapid development and clean, pragmatic design following the Model-Template-Views (MTV) architectural pattern.
* **BSD License:** A family of permissive free-software licenses that imposes minimal restrictions on the redistribution and modification of covered software.
* **Adrian Holovaty:** A software developer, journalist, and musician who co-created Django to streamline web publishing and pioneered data journalism applications.
* **Django Reinhardt (1910–1953):** A pioneering Romani-French jazz guitarist and composer who co-founded the Quintette du Hot Club de France and popularized the "Gypsy Jazz" genre.

Instagram launched in October 2010, and its web backend was built with Django. It became one of the best-known Django users. Other well-known Django sites include Mozilla, Disqus and Nextdoor.

- **Instagram:** A social media platform where people share photos, videos, and messages.
- **Launched:** Officially released and made available to the public.
- **Django:** A Python web framework that helps developers build websites and web applications.
- **Web backend:** The part of a website or application that works behind the scenes. It handles tasks such as processing requests, managing data, and communicating with databases.
- **Backend:** The part of an application that users usually do not see directly but that makes the application work.
- **Built with Django:** Means Django was used as one of the main tools to develop the website's backend.
- **Mozilla:** An organization known for developing Firefox, a web browser, and other internet-related software.
- **Disqus:** An online service that provides commenting systems for websites.
- **Nextdoor:** A social networking platform designed to connect people with others in their local neighborhoods.
- **Social media platform:** An online service where people create, share, and interact with content.
- **Database:** An organized collection of information that software can store, retrieve, and update.

## 2012

### **Ansible**

Michael DeHaan created Ansible in 2012, and Red Hat bought it in 2015. Ansible configures many computers at once from simple text files. It needs only SSH and Python on the machines it manages.

* **Ansible:** An open-source automation platform used for IT tasks such as configuration management, application deployment, and intra-service orchestration, designed to be agentless and simple to deploy.
* **Michael DeHaan:** An open-source developer and author who founded the Ansible project in 2012, previously known for creating Cobbler and working on Fedora systems management.
* **Red Hat:** A leading American enterprise software company specializing in open-source products, including Red Hat Enterprise Linux (RHEL), which acquired Ansible in October 2015 and later became a subsidiary of IBM in 2019.
* **SSH (Secure Shell):** A cryptographic network protocol used for secure remote login and command execution over an unsecured network, serving as Ansible's primary transport layer to manage nodes without installing custom software.
* **Python:** A high-level, general-purpose programming language; Ansible is written in Python and uses Python on remote managed nodes to execute its modules.

## 2018

### **FastAPI: Modern, High-Performance Python Web APIs**

Sebastián Ramírez released FastAPI in December 2018, leveraging modern Python syntax features such as type hints to deliver rapid development speeds and high runtime performance. By using standard Python type annotations, FastAPI automatically handles request data validation, serialization, and open API documentation generation without boilerplate code. Built on top of Starlette for routing and Pydantic for data validation, it fully embraces asynchronous programming (`async`/`await`), placing its performance on par with NodeJS and Go.

* **FastAPI:** A modern, high-performance web framework for building APIs with Python based on standard Python type hints and asynchronous execution.
* **Type Hints:** Native syntax introduced in Python 3.5 that allows developers to explicitly declare data types, improving static analysis, IDE autocompletion, and runtime validation.
* **Pydantic:** A data validation and settings management library using Python type annotations to enforce data structures and serialize complex types.
* **Starlette:** A lightweight ASGI (Asynchronous Server Gateway Interface) framework/toolkit ideal for building high-performance async services in Python.
* **OpenAPI / Swagger UI:** Standardized specifications and interactive web interfaces automatically generated by FastAPI to document and test API endpoints dynamically.
